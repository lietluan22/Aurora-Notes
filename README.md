# Aurora Notes

Aurora Notes é uma aplicação web simples para criar, visualizar e excluir notas diretamente no navegador.

## Funcionalidades

- Criar notas com título e conteúdo
- Listar notas salvas
- Excluir notas
- Salvar as notas no navegador usando `localStorage`

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Clone este repositório:

```bash
git clone [https://github.com/lietluan22/aurora-notes.git](https://github.com/lietluan22/aurora-notes.git)
```

2. Entre na pasta do projeto:

```bash
cd aurora-notes
```

3. Abra o arquivo `index.html` no navegador.
